# 论读书：普通人改变人生的最好方式

## 提要

现在我依旧认为，普通人能改变人生的最好方式就是读书。当然，此读书并非彼读书——我们不能够按部就班地去读死书。从九年义务教育的读书到自己发自内心的读书，这种转变是自己思想层面的一个蜕变。

## 被推着走的人生

为什么说我会这么想呢？因为我就是一个普通人，可以说是比较底层的一个普通人。从小就按部就班地上学、学习、读书，每天跟个陀螺似的上课学习。现在我才后知后觉：**从小到大，我的人生都是被推着走的**——自己没有主见，甚至没有想过自己未来的职业规划。我对自己的未来都是迷茫的。

以至于这样的我处在一个小圈子里，像一个井底之蛙，只能仰望，看不到外面的世界，也不知道如何去学习提升认知，从而提升自我。

为什么我会突然思考这个事情呢？其实我自己也很错愕，我也不知道我为什么会思考这些事情。我觉得应该是社会现实和压力迫使我去思考了。我逐渐地发现，身边人似乎都只在乎吃喝玩乐，而不在乎去真正提升自己。

## 读书：思想上的蜕变

转变我的，是读书。

{% note info %}
当我开始真正读书之后，我发现一个最大的好处：**我的所有经历、所有思想感情，都被前人分析得明明白白、特别透彻了。**
{% endnote %}

普通人想要在现实生活接触到那些伟大的头脑，是几乎不可能的。唯一的途径就是读书。你在书中可以了解他们的事迹，你经历过的人生轨迹也一定会在前人的书中有一些记载——即使不是完全相似，也能给你很大的启发，让你从中学习到很多东西。

为什么说读书是最好的方式？

因为在这个信息碎片化的时代，短视频、朋友圈、热搜给你的都是零散的、不需要深度思考的信息。而书是经过时间和思考沉淀下来的东西。**一本书可能花了作者几年甚至几十年的心血，而你只需要几十块钱、几个小时，就能把一个人毕生的思考装进自己的脑子里。** 这笔账怎么算都划算。

当然，我说的这些都不能一概而论，毕竟我也才读书没多久，我也只是读了一些书，然后有自己的一些思考罢了，我自己的阅读量也还不高。

但我至少意识到了一件事：

**读书让我从一个「被推着走的人」，变成了一个「自己会想往哪走的人」。**

这大概是读书给我最大的礼物——它没有直接告诉我答案，但它让我开始学会问问题。

## 一个简单的建议

如果你也想开始读书，但又不知道从哪下手，我的建议很简单：

不要一上来就啃那些「必读书单」里的名著——那些对你来说可能太早、太沉重。从你感兴趣的领域开始就行。

- 你喜欢历史？那就从一本讲历史故事的书开始。
- 你对心理学好奇？那就找一本通俗心理学入门。
- 你感到迷茫？那看看那些也迷茫过的人是怎么走出来的。

**关键在于：不是为了完成任务而去读，而是因为你想知道。**

哪怕你每天只读十页，坚持一年也是三千多页。这三千多页里，藏着另一个人的一生、一个时代的轮廓、一种你从未想过的活法。

## 趁还来得及

值得庆幸的是，现在的我才 14 岁，我还有很多时间来打磨自己、提升自己！

{% note info %}
14 岁的时候意识到读书的重要性，和 24 岁、34 岁才意识到，是完全不一样的。前者还有大把的时间去积累、去试错、去成长；后者往往会后悔——「我怎么没有早一点开始？」
{% endnote %}

所以如果你也还年轻，请珍惜这段时光。不需要做到完美，不需要和别人比速度。只要你在读，你在想，你在用自己的脑子判断——**你就已经走在了大多数人的前面。**

---

*十四岁的天空，正好够装下所有的好奇与可能。愿你我都能在书中，找到那个真正想成为的自己。*
