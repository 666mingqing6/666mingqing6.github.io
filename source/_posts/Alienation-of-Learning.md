# 论学生时代的「学习异化」

## 提要

为什么有人学得如饥似渴，有人学得如坐针毡？明明都是学习，感受却天差地别。这篇文章从马克思的「劳动异化」出发，探讨学习异化的根源，以及我们该如何在被迫的学习中，找回那一份属于自己求知欲。

## 一个奇怪的现象

大家都上过学，都有过学生时代。不知道大家有没有发现一个现象：

那些学习好的人，天天都在学，仿佛学不厌一样，学得非常快乐。而反观那些学习不是很好的人，仿佛根本提不起兴趣来——一提到学习，就好像泰山压顶一样。

有些人说：「学习哪快乐了？每天做题做到手软，做到心累，考试还是那点成绩。」

但也有人说：「解出难题的那一刻，成就感还是满的，挺让人愉悦的。」

这就很有意思了——**明明是同一件事，为什么我们会有完全不一样的感觉呢？**

难道有些人生来就爱学习，有些人生来就厌学？恐怕没那么简单。

## 从现象到本质——引入「学习异化」

要解答这个问题，我们得先意识到一件事：**你讨厌的也许根本不是学习本身，而是你和学习之间那种被扭曲了的关系。**

比如你明明对二战历史很感兴趣，刷视频能刷一晚上，可一旦它变成考试范围、明天要默写，你瞬间就不想碰了。书还是那本书，知识还是那些知识，**变的是什么？是你和学习之间的关系。**

好，现在就可以提我的题目了——**「学习异化」**。这个词是我从马克思的「劳动异化」里面改写而来的。

## 什么是「学习异化」

### 马克思说的劳动异化

马克思说，劳动应该是人自由的有意识的活动。

什么意思呢？就是说劳动本应该是我们主动去创造、实现自己想法的过程。就像一位作家用笔记录生活的点滴，一位同学解开困扰已久的数学题，一位画家看见美丽的景色用笔墨记录下来——**那种发自内心的成就感，才是劳动本来的面目。**

可马克思也发现，在很多时候，劳动变了味。变成了什么呢？变成了一种被迫的、强迫的、为了谋生的手段。

拿同学们学习生活中的一些日常来举例子：

- 如果你是因为好奇某个历史人物，自己去查阅资料，你会觉得津津有味；但如果是**为了应付明天的检查背诵而去背**，那简直生不如死，度秒如年，提不起一丁点儿兴趣来。
- 同样是值日，如果你主动把教室扫干净，让教室变得焕然一新，你会很有成就感；但若只是**被扣分制度和老师的压力逼迫着去做**的话，那么连举起扫帚都是奢望。

**劳动本身没有变，变的是什么？是我们与劳动的关系！** 我们从劳动的主人变成了劳动的奴隶。

### 学习异化的四个层面

就像马克思的劳动异化有四个层面一样，学习异化同样如此：

**学生与「学习产品」异化：** 学习本该产出的是知识、见识和思考能力。但现在它产出的是分数、排名和证书。这些「产品」反过来定义了学生——分数高就是好学生，分数低就是差学生。你不再因为学到了东西而快乐，而是因为分数高才觉得自己「合格」。**产品本该服务于人，现在人却反过来被产品定义。**

**学习过程异化：** 学习本来应该是主动探索、好奇驱动的过程。但现在学习变成了被动的、被迫的——刷题、背书、应付检查。你在学习过程中感受不到自主的快乐，只觉得在完成一个叫做「学习」的 KPI。就像一条流水线上的工人，重复着同样的动作，却不知道自己在生产什么。

**人的求知本质异化：** 人天生就有好奇心，这是人类最珍贵的特质之一。婴儿会抓东西往嘴里塞，小孩子会不停地问「为什么」——这些全部都是学习，而且是自发的学习。但当学习变成一种竞争工具，人就失去了这种能力——你不再因为想知道而学，而是因为「该学了」。求知欲被掏空了，只剩一个空壳。

**人与人关系异化：** 「学霸」和「学渣」被标签化，同学之间不再是共同探索的同伴，而是互相竞争的对手。你不敢问问题，怕别人觉得你笨；别人也不愿分享，怕你超过他。学习变成了一场零和博弈，却忘了知识本来是可以共享的。

{% note info %}
当各位觉得自己的读书是为了分数、为了爸妈的期望的时候，那么你就不再是真的读书了。当你读书是被推着走、被强迫着走，那么你绝不会喜欢上读书。你会越来越像个机器——有电你就被逼着走，没电了你就真的没电了。
{% endnote %}

## 学习本该是什么样子？

我想先问一个问题：**各位，你们有多久没有为自己学过一样东西了？**

不是为了考证，不是为了应付老师的检查，不是为了某一样东西而被迫去学——就单纯因为：你好奇，你想知道，你心里有一个问题追着你跑。

你回忆一下你小时候：你看课外书，你学折纸，你学画画。没人逼你，没人给你定 KPI。你学，只是因为你想学。那个时候学习不是投资，**学习是你跟这个世界相处的方式。**

马克思在《1844 年经济学哲学手稿》里面讲过一句很深刻的话：

> 异化劳动把人的生命活动变成了维持生存的手段。自由自觉的活动才是人类的类本质。

学习应该是最自由自觉的——**你心里冒出一个问号，你追着它跑，它把你带到一个你自己都没想到的地方。** 这才是学习原本的模样。

## 为什么我们回不去了？

但是现在变了，不一样了。

学习从「想知道」变成了「需要学」。

你从探索者变成了被迫运转的机器。老师、社会和外界给你电，你就能走；这个电没了，你就彻底没力了。

你在课堂上给自己打补丁——你不是在学习，**你是在给身上这台名为「我」的机器做系统升级。**

一个完整的人，不应该是只会在课堂这个流水线上给自己打补丁的人。一个完整的人，他学一样东西不只是为了应付 KPI，而是为了满足心里那一小簇跳动的火苗。他能够把自己的本职工作、社会要求的工作做好，也能在某一个下午心无挂碍地翻开一本和工作毫无关系的书。

他在创造经济价值的同时，也在创造着只有他能创造的东西——一种独特的思考，不被市场定义的想象。这些东西不写在任何试卷上。但社会的进步、文明的积累，**靠的从来不是那些所谓的分数，而是一个又一个完整的人，把他们身上最鲜活的那部分拿出来，留给这个世界。**

## 对教育体系的反思

与此同时，我也想批判一下现在的教育体系。

现在的教育，我觉得太差劲了。

各位想一下：你们上课的时候，老师讲知识点的时候，是不是就直接告诉你了？他从来不会问：「各位想一下，这个知识点是怎么来的？有什么用？怎么发现的？」

**我们现在的教育，不会引导学生自己思考。**

它教你怎么解题，但不教你怎么提问；它教你怎么得分，但不教你怎么好奇。整个系统像一台巨大的复印机，把标准答案复制到一代又一代人的脑子里。

资本需要的只是一批又一批的标准零件。

大家要意识到：如果你没有自己的思想意识，没有自己独立的思考，那么你学习毕业之后出了社会，只会在重复的工作上浪费自己的生命——成为流水线上一批又一批的标准零件，成为一个社会底层运转需要的劳动价值。

但整个社会和文明进步真正需要的，是**你这一个独一无二的人**。只有在你成为真正的人之后，你身上最珍贵的东西——你的创造力、你的同理心、你对美的感受、你对不公的直觉——才能自然地流淌出来，而不是被焦虑地堵死在心里。

## 如何在异化中找回自己

大家一定要学会在被迫的劳动中，主动找回一点点为自己劳动的感觉。

你说你不想再上课，那你就能不上课了吗？你说你不想考试，你就不用考试了吗？可见我们生活中的被迫劳动是随处可见的。但是如果我们带着这样「不想」的心态去劳动的话，那么你会非常累。

或许我们可以试着这样去改变：

你不想上课，本质是什么？因为上课很无聊，学习知识点很枯燥。但如果你潜心去听课、潜心钻研知识点的话，那么你会发现很有意思——那些题目本身实质上仍在知识点的框架里面打转，只是换了个方式来问你。**一旦你理解了那个底层逻辑，题目就不再是敌人，而是同一个问题的不同面孔。**

但是由于很多人没有意识到这个问题，上课发呆、游神、睡觉，然后就漏了知识点。一次两次还好，可以补回来，但一旦次数越积越多，你就会越听越不懂。你越不懂，你就越不知道；你越不知道，就越不想学；你越不想学，就越不想去问；你越不问，就越不知道——**陷入恶性循环。**

所以我今天要说的，不是否定现实社会中的压力与规则，与无法避免的被迫劳动。而是要告诉各位：**劳动本身是中性的**——是快乐还是痛苦，取决于我们与劳动的关系。你知识点不懂，你可以去找老师问，可以补回来。**但更重要的是：你要试着在每一件被迫去做的事情里，找到一点点属于你自己的主动权。**

### 自我检测：你是否处于学习异化中？

{% note info %}
- 拿到试卷你第一时间看的不是题目，而是分数？
- 你学一个东西之前最先问的是「考不考」？
- 放假之后你从来不会主动翻开任何一本书？
- 你觉得自己学的东西跟生活毫无关系？
- 你已经很久没有因为「想知道」而去查过什么东西了？

如果你中了三条以上，那么你可能已经处于学习异化之中了。
{% endnote %}

意识到自己在异化中，不是让你绝望，而是让你觉醒。**因为只有当你看到笼子的时候，你才有可能走出去。**

### 对「无用之学」的辩护

读一本你不会引用的闲书，学一门你永远不会靠它赚钱的手艺，研究一个跟你工作毫无相关的话题。这种「无用」，是人对重复运转的生活最后的叛逆，是人对资本最后的叛逆。资本说你每一分钟都得有用，但你的心需要一些不结账的领地。

学会与自己相处——这很难，它在任何平台都搜不到，也不需要老师。你需要的只是一个下午：你忽然间想到一个莫名其妙的问题，然后你跟着它走了一会儿。你忘了时间，也忘了目的，也忘了自己够不够努力。

那一刻，你回到了自己童年——趴在书桌上画小人的那个孩子。

**那个小孩没有变，他一直在等你，用真正属于人的方式重新开始学习。**

## 结语

**学习从来不是为了应付考试，学习是为了解惑。**

困惑不是你的敌人，是你的老师。你心里有个问号，你追着它走——这种冲动不是焦虑，是你的生命力在往外长。这种学习没人给你打成绩，但它会让你变得更有重量，让你变得更加有活力，变成一个真正的人。

{% note info %}
一种是为了追求真理而学，一种是为了追逐名利而学。

我相信各位应当会选择前者！
{% endnote %}

*学习不是一场通关游戏，而是一次与自己对话的旅程。愿你在这条路上，找回那个「想知道」的自己。*
