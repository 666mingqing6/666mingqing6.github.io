隐私政策

隐私政策

本页说明 Lumoes Blog（blog.646474.xyz）如何收集、使用与保护你的个人信息。本站为纯静态个人博客，数据收集极少。

一、隐私承诺

本站由 Re.Lumoes 个人运营，承诺：

  1. 最小化收集：只收集站点运行所必需的数据
  2. 匿名化处理：统计数据不含个人身份信息
  3. 不主动售卖：不会将你的信息出售给任何第三方
  4. 透明公开：所有数据收集行为在本页如实披露

二、数据收集范围

1. 自动收集的数据（匿名）

当你访问本站时，以下第三方服务会自动记录匿名访问数据：

数据项 收集方 用途 是否可识别个人
访问页面 URL 51.la 统计热门文章 ❌ 否
访问来源 51.la 分析流量来源 ❌ 否
访问时间 51.la 分析访问时段 ❌ 否
浏览器类型 51.la 兼容性分析 ❌ 否
屏幕分辨率 51.la 响应式优化 ❌ 否
IP 地址（脱敏） 51.la 地域分布统计 ⚠️ 部分脱敏

2. 主动提交的数据

当你在本站进行以下操作时，会主动提交数据：

💬 评论

  • 收集内容：昵称、邮箱、网址（可选）、评论内容
  • 存储位置：Twikoo 评论系统（部署于 Vercel/腾讯云）
  • 用途：评论展示、回复邮件通知（如启用）
  • 公开展示：昵称、网址、评论内容对所有人可见；邮箱不对公众展示
  • 保留期限：除非主动要求删除，否则长期保留

🔍 站内搜索

  • 收集内容：搜索关键词
  • 处理方：Algolia / 本地搜索
  • 用途：返回搜索结果，可能用于优化搜索体验
  • 公开展示：❌ 不公开

💰 赞助

  • 收集内容：支付信息由微信/支付宝直接处理，不经过本站服务器
  • 本站可见：仅能看到赞助金额与留言（若你主动留言）
  • 存储位置：支付平台，本站不存储任何支付凭证

  • 存储：AI 服务商可能按其政策记录请求内容

三、数据使用目的

本站收集的所有数据仅用于以下目的：

目的 数据来源 必要性
改善站点内容质量 51.la 访问统计 改进型

本站明确承诺不将数据用于：

  • ❌ 精准广告投放（本站无广告）
  • ❌ 用户画像构建
  • ❌ 数据出售或共享给营销方
  • ❌ 跨站行为追踪

安全措施

  • 静态托管：本站为纯静态站点，托管于 GitHub Pages，无数据库泄露风险
  • HTTPS 加密：全站强制 HTTPS，传输过程加密
  • 评论数据：Twikoo 评论数据存储于 Vercel/腾讯云，由其安全机制保护
  • 不存储密码：本站无登录系统，不存储任何密码信息

数据保留

51.la 统计数据 由 51.la 政策决定 联系 51.la
评论数据 长期保留 联系博主删除
搜索记录 会话级或由 Algolia 决定 自动清除
AI 请求内容 由 AI 服务商决定 联系服务商

五、你的权利

作为本站访客，你拥有以下权利：

1. 知情权

你有权了解本站收集了你哪些数据（见本政策第二节）

2. 访问权

你可以通过以下方式访问你提交的数据：

  • 评论：直接在对应文章下查看
  • 其他数据：联系博主查询

3. 更正权

若你的评论信息有误，你可以在评论区修改，或联系博主协助更正。

4. 删除权

你可以随时要求删除你的评论数据：

  • 自助方式：在评论管理界面删除（如已登录）
  • 联系博主：通过 GitHub 或 留言板 提出
  • 处理时限：收到请求后 7 个工作日内 处理

5. 拒绝权

  • 安装广告拦截插件屏蔽 51.la 统计脚本
  • 不使用评论功能
  • 不使用 AI 摘要（可手动关闭该区域）

6. 可携带权

你可以要求导出你的评论数据，博主将在 7 个工作日内以 JSON 格式提供。

六、未成年人保护

本站内容主要面向技术爱好者与一般读者，不针对 14 周岁以下未成年人。

  • 若你是未成年人，请在监护人指导下使用本站
  • 监护人发现未成年人的个人信息被不当收集，可联系博主删除
  • 本站不会主动收集未成年人个人信息

七、第三方链接说明

本站文章中可能包含指向第三方网站的链接，本站对第三方网站的隐私实践不负责任。建议你查阅你所访问的第三方网站的隐私政策。

本站常见外部链接包括：

第三方 链接用途
GitHub 开源项目引用、博主主页
YouTube / Bilibili 视频嵌入
BootCDN 静态资源加速
微信/支付宝 赞助支付

八、政策变更

本隐私政策可能随站点功能调整或法律法规要求而更新：

  • 重大变更：在本页显著位置公示 30 天后生效
  • 次要变更：直接更新本页，更新最后修改日期
  • 不溯及既往：政策变更不影响变更前已收集数据的处理方式

建议你定期查阅本页以了解最新政策。
