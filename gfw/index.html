介绍
#

防火长城（Great Firewall，GFW），中国国家防火墙，或简称为墙、防火墙等，中共中央网信办称其为数据跨境安全网关，是对中华人民共和国过滤国际互联网境外内容的软硬件系统集合乃至整个中华人民共和国网络审查系统的代称。防火长城不是中国特有的一个专门单位，而是由分散部门的各服务器和路由器等设备，加上相关公司的应用程序构成，其监控所有经过国际网关的通讯，对认为不符合中国官方要求的传输内容，进行干扰、阻断、屏蔽。由于中国网络审查广泛，中国大陆内含有“不合适”内容的网站，会受到政府直接的行政干预，故防火长城主要作用在于分析和过滤中国境外网络的信息。自本世纪初以来，防火长城由国家计算机网络与信息安全管理中心（CNCERT）运营和维护

随着防火长城逐渐为人熟知，“墙”一词有时也被用作动词，“被墙” 即指网站内容被防火长城所屏蔽，“翻墙” 也被引申为突破网络审查浏览中国大陆境外被屏蔽的网站或使用服务的行为。

核心论点
#

GFW 的核心政治价值并不只是“让中国人打不开几个外国网站”，而是改变信息进入、传播、组织和验证的成本结构。 它最终产生的结果，是让中国大陆形成一个相对独立的信息生态，使政治议题更难形成跨境传播、跨平台传播和大规模社会动员。

但 GFW 也不是一堵“把所有信息都挡死”的墙。它真正高效的地方在于：它只需要提高获取某些信息的成本，就足以改变绝大多数人的信息消费行为。

一、GFW 的政治作用到底有多大？
#

如果粗略按照政治功能划分，我会给它这样一个评价：

功能政治影响
阻断境外信息进入★★★★★
降低跨境政治传播★★★★★
削弱社会动员能力★★★★★
塑造国内舆论生态★★★★★
增强政府议程设置能力★★★★☆
促进国内互联网产业生态★★★★☆
让普通人完全不知道境外信息★★☆☆☆
消灭反对意见★★☆☆☆

最后两项特别重要。

GFW 并没有让中国人“不知道有不同意见”，而是让这种不同意见更难成为日常信息环境的一部分。

这两个概念差别非常大。

换句话说 就是GFW的作用最主要的是：阻止政治信息和不同意见在中国互联网的流通与传播

让公众难以接触到不同意见和信息，公众大多只能接触到官方宣传的意识形态。

以至于久而久之 中国公民会默认的下意识的认为：中国的政治很稳定很自由

但实则真的是这样吗？

二、GFW 最重要的政治作用：不是“封锁”，而是制造信息边界
#

假如有一个中国普通初中生：

他每天可能会：

  • 微信聊天
  • 刷抖音
  • 看 B 站
  • 搜百度
  • 看微博
  • 看知乎
  • 看小红书
  • 使用国内 AI
  • 看国内新闻

这些事情都不需要跨越 GFW。

于是在他的世界里，他认为他自己生活在一个完整、便利、内容极其丰富的互联网生态里。

这产生一个非常重要的效果：

（中国的）“互联网”本身没有消失，但“互联网”与“全球互联网”被人为分成了两个空间。

例如：

互联网生态对比

微信 → 微博 → 百度 → B站 → 知乎 → 抖音 → 小红书

Google → YouTube → Reddit → X → Wikipedia → Instagram → Facebook → Telegram → Discord → 外媒

二者并不是完全没有交集，但存在着非常大的鸿沟

Freedom House 2025 年的报告将中国的互联网自由度评为 9/100，并认为中国长期处于全球互联网自由度最差的国家之列。报告还指出，中国政府控制连接国际互联网的主要网关，这构成了 Great Firewall 的基础。ecoi.net

三、一个日常的例子：你突然想查一个政治事件
#

假设发生了一件非常有争议的事情。

你看到国内平台上的说法：

“这是一起普通事件。”

你产生怀疑，于是信息核查路径在不同网络环境下有很大区别：

信息核查路径

flowchart TD
    A[Google] --> B[Wikipedia]
    B --> C[BBC / Reuters / AP / NYT]
    C --> D[YouTube]
    D --> E[X]
    E --> F[Reddit]
    F --> G[当地人的第一手信息]
    G --> H{互相交叉验证}
经信息整合和交叉验证后得出结论
flowchart TD
    A[百度] --> B[知乎]
    B --> C[微博]
    C --> D[B站]
    D --> E[微信公众号]
这些平台本身受到中国国内法律和内容治理体系约束。

这意味着一个非常关键的变化：

不是“你没有信息”，而是你获取信息的来源集合发生了结构性变化。

这就是 GFW 深层的政治作用之一。

四、GFW不需要封锁所有信息
#

这是理解 GFW 关键的一点。

很多人想象的审查制度是：

政府发现一句反对政府的话 → 删除

但在现代互联网审查中真正有效的方式往往不是这么简单，

Gary King、Jennifer Pan 和 Margaret Roberts 完成了一项研究，他们分析了中国大量社交媒体内容，他们发现一个非常有意思的规律：

中国网络审查并不是主要针对“批评政府”的内容。

甚至一些非常尖锐的政府批评，也可能不会立即被删除。

真正容易触发审查的是：能够产生、强化或者组织集体行动的内容。

也就是说：

“我讨厌政府。”

可能未必是最危险的。

而：

“大家明天晚上八点到这里集合。”

政治风险就完全不同。

这项研究通过分析大量社交媒体帖子得出了这一结论：剑桥大学出版社

事实上 在中国的社交媒体上 也大量充斥着批判政府和现实的不满的视频或帖子

不过大多影响力都较弱 或者流量惨淡 因为流量大的都被官方压制了

真正触发敏感的往往是具有集结信号的视频或帖子

单纯的批判反而不那么容易被封禁

五、为什么“组织能力”比“批评政府”更重要？
#

想象一个极端例子。

有 100 万个人都认为：

“这个政策不合理。”

这其实未必会产生什么政治结果。

因为：

flowchart TB
    subgraph 彼此不知道
        direction LR
        A[A：我不满]
        B[B：我不满]
        C[C：我不满]
        D[D：我不满]
    end

大家彼此不知道。

但如果突然出现：

flowchart TD
    A[A] <--> B[B]
    B <--> C[C]
    B --> D[D]
    D <--> E[E]
    D --> F[100 万人]

事情就完全不同了。

所以政治学里有一个非常重要的区别：

private opinion（私人意见）

和

collective action（集体行动）

互联网对于政府最可怕的地方并不是让一个人产生反对意见。

而是：

让拥有相似意见的人发现彼此存在，并能够迅速组织起来。

GFW + 国内平台审查体系，在政治上的重要功能之一，就是提高这种跨区域、跨平台、跨国界的组织成本。

六、2022 年“白纸运动”
#

22年的白纸运动可以说是体现中国互联网政治作用的一个非常典型案例。

2022 年中国多地发生与“动态清零”政策相关的抗议活动。

其中一个非常特殊的地方在于：

信息传播并没有被完全阻断。

人们开始：

  • 使用 VPN
  • 使用境外社交媒体
  • 分享视频
  • 使用隐晦表达
  • 使用图片
  • 使用谐音
  • 使用表情
  • 通过 Telegram 等境外平台传播

Freedom House 的报告也记录了这一时期大量中国网民利用翻墙工具获取和传播与抗议相关的信息。Freedom House

这说明：

GFW 很强，但不是绝对密封的。

而更Interesting的是：当信息突破 GFW 后，它的传播速度可能会发生变化。

七、加强封锁反而可能刺激翻墙
#

这一点非常反直觉。

政治学研究者研究了 Instagram 在中国被封锁之后的用户行为。

研究发现：

Instagram 被封之后，一部分原本只是普通社交媒体用户的人，反而开始转用 VPN，并进一步进入 Twitter、Facebook 等此前已经被封锁的平台。

而且其中一些用户随后开始接触政治抗议相关内容以及中国海外活动人士网络。剑桥大学出版社

这意味着：

封锁不是线性的。

不是：

flowchart LR
    A[封锁增加 10%] --> B[信息减少 10%]

现实上更可能是：

flowchart TD
    A[封锁] --> B[用户产生绕过需求]
    B --> C[学习 VPN / Tor / Proxy]
    C --> D[进入更大的境外信息网络]
    D --> E[接触以前根本不知道的信息]

所以 GFW 有一个很有意思的副作用：

它能够隔离大多数人，却也可能把少数主动突破的人变成信息获取能力更强的人。

八、为什么绝大多数人不会翻墙？
#

假设：

翻墙需要 10 分钟。

对于一个技术爱好者来说：

“10 分钟而已。”

但对于普通人：

“为什么我要花 10 分钟？”

他本来可以用这10分钟：

  • 微信聊天
  • 抖音娱乐
  • B站学习
  • 淘宝购物
  • 百度搜索
  • 看国内新闻

那么他没有足够强的动机去翻墙。

这就是摩擦成本（friction cost）。

GFW 并不需要做到：

100% 阻止访问。

它只需要做到：

让访问的成本高到大多数人不愿意付。

经济学上管这个叫“理性无知（rational ignorance）”

意思是：获取某种信息/知识需要成本，而收益不确定、分散或对个人不大；当获取成本 > 预期收益时，理性人就会选择“不知道”，而不是去获取。

对应到GFW上：

  • 翻墙要花 10 分钟、技术门槛、风险 → 获取成本/交易成本
  • 这 10 分钟可以聊天、刷抖音、购物、搜索 → 机会成本
  • GFW 不需要 100% 封锁，只要把成本抬高到多数人觉得“不划算” → 多数人理性地选择不翻墙

更底层的机制是 交易成本 / 摩擦成本 / 搜寻成本，表现为 需求定律：使用某种东西的成本上升，需求量就下降。

九、单向度的人
#

Yuyu Chen 和 David Yang 在 American Economic Review 发表了一项实验研究。

他们给中国受试者提供了访问未审查互联网的条件，并持续追踪其信息消费、知识、政治态度等变化。

结果非常令人唏嘘：

第一
#

单纯提供自由互联网：

并不会自动让所有人开始疯狂搜索政治敏感信息。

这意味着：

“只要翻墙，中国人就会集体反政府。”

这种说法是不成立的。

第二
#

但是，如果主动鼓励他们获取未审查信息：

他们的信息获取会明显增加。

而且：

这种影响并不是短期的。

接触这些信息后，他们的知识、信念、政治态度以及部分行为意向都发生了持续变化。AEA Publications

这给 GFW 的政治意义提供了非常重要的实证解释：

GFW 的作用不是把所有人都变成“被洗脑的人”，而是显著改变一个人接触不同观点的概率。

这两者完全不同。

换句话说 人无法想象自己未了解过 未接触过的东西 你把一个墙内人拉到墙外 如果你不给他引导 不给他看一些帖子 他自己永远也不会搜索“中国信息封锁社会问题”

这实际上背后是一个认识论的问题的。

十、再举一个非常普通的场景：Wikipedia
#

假设一个中国学生正在写：

“马克思主义与自由主义有什么区别？”

他可能会：

学术资料获取路径

flowchart TD
    A[百度] --> B[知乎]
    B --> C[B站]
    C --> D[中国教材]
    D --> E[中文公众号]

flowchart TD
    A[Wikipedia] --> B[Stanford Encyclopedia of Philosophy]
    B --> C[JSTOR]
    C --> D[Google Scholar]
    D --> E[国外大学课程]
    E --> F[不同意识形态的论文]

注意：

开放互联网并不意味着后一组内容一定正确。

Wikipedia 也会错。

国外媒体也会有偏见。

学术论文也会互相争论。

但关键是：

你拥有了更多互相竞争的信息来源。

而政治控制最忌讳的恰恰不是“有人说错话”，而是：

信息来源之间可以自由竞争。

古时候 封建制度往往采用“愚民政策” 并不是让人民完全不了解知识 完全不学习知识 那样只会让全部人都变成傻子 ， 而是让人民只接受一种教育

这一点我希望大家好好想想。

十一、GFW 实际上改变的是“认识论环境”
#

如果把问题往哲学方向推一步，就会变得非常 Interesting

普通人判断一个政治事实：

“XXX 是真的。”

实际上需要：

flowchart TD
    A[事实] --> B[信息来源]
    B --> C[传播]
    C --> D[验证]
    D --> E[比较不同解释]
    E --> F[形成判断]

GFW 可以影响其中至少三个环节：

① 信息来源
#

你能不能看到某个来源？

② 信息传播
#

别人能不能把某个来源传播给你？

③ 信息竞争
#

不同解释能不能在同一个空间里竞争？

所以 GFW 的政治影响实际上不是简单的：

“阻止你说话。”

而更接近：

“改变你能够听见什么、在哪里听见、听见多少、以及与谁进行比较。”

十二、自我审查
#

假设一个人知道：

“某些话发出来可能被删除。”

甚至进一步知道：

“某些事情可能引起平台处罚。”

那么他未必需要真的被处罚。

他可能自己就不说了。

形成：

flowchart TD
    A[法律风险] --> B[平台审查]
    B --> C[用户预期]
    C --> D[自我审查]
    D --> E[最终公开表达减少]

这叫 chilling effect（寒蝉效应）。

Human Rights Watch 也指出，中国网络用户普遍存在自我审查现象，而政府控制主要信息渠道和互联网访问进一步强化了这种环境。人权观察

所以：

一个成熟的审查体系，不需要把所有反对者抓起来。

只要让大家知道：“哪些东西最好别碰。”

很多人就会主动避开。

十三、GFW 的政治经济作用：培养国内替代平台
#

这个效果经常被忽略。

比如：

全球互联网中国大陆对应生态
Google百度
YouTubeB站 / 优酷等
X微博
WhatsApp微信
Instagram小红书等
Google Maps高德 / 百度地图
Reddit知乎等

当然，这些并不是严格的一一对应，也不能说它们功能完全相同。

但从生态角度看：

外国互联网平台被限制进入 + 国内平台获得巨大用户市场

客观上给中国互联网企业创造了巨大的国内市场空间。

而国内平台又必须遵守中国的互联网监管制度。

于是形成一个闭环：

flowchart TD
    A[境外平台进入困难] --> B[国内平台获得用户]
    B --> C[国内平台受监管]
    C --> D[用户集中在国内平台]
    D --> E[信息治理更加容易]
    E -.-> A

这也是为什么我认为：

GFW 不应该仅仅理解成“网络防火墙”。

它实际上参与塑造了一个完整的数字政治生态系统。

十四、GFW ≠ 中国全部互联网审查
#

严格来说，GFW和中国互联网审查不是一回事。

可以把中国网络信息控制粗略理解成四层：

flowchart TD
    L1[① 国际出口控制] --> G[GFW]
    L2[② 国内平台审查] --> P[微信 / 微博 / 抖音 / B站……]
    L3[③ 实名制与账号治理] --> A[账号处罚 / 封禁 / 身份关联]
    L4[④ 法律与行政压力] --> X[删除 / 约谈 / 行政处罚 / 刑事责任]

GFW 只是第一层。

因此如果有人说：

“中国互联网审查 = GFW。”

这是技术上不准确的。

真正完整的体系是：

网络基础设施控制 + 平台内容审核 + 实名制 + 行政监管 + 法律责任 + 信息宣传体系。

中国 2024 年发布、2025 年起实施的《网络数据安全管理条例》也明确规定网络数据安全治理坚持中国共产党的领导，并建立了较完整的数据安全监管框架。国家互联网信息办公室

十五、GFW 的真正政治价值：降低“信息外部性”
#

假设你自己看了一条境外政治新闻，这只是：

个人信息获取。

但如果你把它：

转发给 10 个人

再由他们：

转发给 1000 人

最后：

100 万人看到。

那么信息就产生了网络效应。

所以政府真正担心的往往不是：

“这个人知道了一件事情。”

而是：

“这个人知道了以后，会不会让另外一万人也知道？”

因此：

个人翻墙 ≠ 最大政治威胁。

真正具有政治意义的是：

信息 + 社交网络 + 传播 + 组织能力

形成：

flowchart TD
    A[信息] --> B[认知]
    B --> C[共同认知]
    C --> D[群体身份]
    D --> E[组织]
    E --> F[集体行动]

GFW 最重要的作用之一，就是尽可能切断这条链条中的跨境部分。

十六、那么它到底“有多有效”？
#

如果一定要给一个比较尖锐的评价：

分维度评价

  1. 对普通人的日常生活

    **非常有效。** 因为绝大多数人不会主动折腾 VPN、代理、Tor、海外账号。

  2. 对信息传播

    **非常有效，但不是绝对有效。** 热点事件仍然可以通过下列方式突破： - 截图 - 谐音 - 图片 - 隐喻 - 加密通信 - VPN - 境外平台 - 口耳相传

  3. 对政治思想

    **有效，但无法控制人的思想本身。** 你可以限制： > “他看到什么。” 但很难完全控制： > “他看到以后怎么想。”

  4. 对政治组织

    **尤其有效。** 因为组织需要： > 通信 + 共同信息 + 信任 + 协调。 而网络审查恰恰能够增加这些环节的成本。 这也是为什么政治学研究特别重视“集体行动”这一点。[剑桥大学出版社](https://www.cambridge.org/core/journals/american-political-science-review/article/how-censorship-in-china-allows-government-criticism-but-silences-collective-expression/C7EF4A9C9D59425C2D09D83742C1FE00?utm_source=chatgpt.com)

十七、GFW 也不是“万能盾牌”
#

它存在几个非常明显的局限。

① 技术上永远存在突破
#

只要存在：

加密通信 + 境外服务器 + 新协议

就很难做到永久绝对封锁。

GFW 用了 DNS 污染、IP 注入、SNI 等多种技术性干预方式；长期测量研究曾在数亿域名的测试中发现大量被过滤域名以及明显的过度拦截现象。arXiv

② 精英和技术人员更容易绕过
#

这产生一个很有意思的不平等：

flowchart LR
    A[普通人] --> B[国内互联网]
    C[技术人员] --> D[VPN / Proxy / Tor]
    D --> E[全球互联网]

于是：

信息封锁并不是平均作用于所有人。

懂技术的人往往比普通人拥有更大的信息获取能力。

③ 信息开放不一定自动导致政治反对
#

前面那项 AER 实验恰恰证明：

给一个人自由互联网 ≠ 他马上变成政治异议人士。AEA Publications

人的政治态度受到：

  • 家庭
  • 教育
  • 民族认同
  • 经济利益
  • 社会环境
  • 个人经历
  • 价值观

等大量因素影响。

所以把 GFW 描述成：

“洗脑机器”

其实是过度简化。

十八、我的总结
#

如果让我用一句非常尖锐、但尽可能学术化的话评价：

GFW 最重要的政治功能，不是让中国人“什么都不知道”，而是让中国大陆的信息环境具有高度的边界性，使国家能够显著提高境外信息进入、跨境传播和社会动员的成本，从而维持一个相对独立、可监管、可塑造的国内公共信息空间。

它真正改变的是：

信息的概率分布。

不是：

“你绝对看不到 X。”

而是：

“你看到 X 的概率显著降低；看到它需要付出额外成本；看到以后也更难把它迅速传播给大量其他人。”

这三个效果叠加起来，政治意义就非常大。

信息获取成本
#

假设一个中国学生突然对某个政治问题产生疑问。

两条路径对比

产生疑问 → Google → Wikipedia → 外媒 → 学术论文 → YouTube → X → Reddit → 和不同国家的人交流 → 得出自己的判断

产生疑问 → 百度 → 国内平台 → 国内媒体 → 国内讨论区 → 如果答案不满意 → 才考虑翻墙 → 学习工具 → 注册境外账号 → 找到信息 → 再验证信息真实性

注意：

两个人最后完全可能得出相同结论。

GFW 并不能决定最终结论。

但它可以显著改变：

这个人需要走多远，才能看到另一种答案。

而这恰恰是它最深层的政治作用。

所以如果你正在研究 “互联网审查究竟如何影响人的政治认知”，我建议不要停留在“GFW 封锁了哪些网站”这个层面，而应该继续研究三个概念：

三个值得深入的概念

  1. ① Agenda Setting（议程设置）

    研究议题如何被选择性地呈现与放大。

  2. ② Chilling Effect（寒蝉效应）

    研究威慑预期如何让表达在发生之前就被自我抑制。

  3. ③ Collective Action / Mobilization（集体行动与社会动员）

    研究分散的不满如何被组织成集体行动，以及这种组织成本如何被审查体系抬高。

这三个概念结合起来，基本就能解释为什么一个“防火墙”最终会成为一个政治治理工具。
